# Word-Add-in-Copilot-Public

Локальная надстройка для Microsoft Word на Windows. Анализирует договоры и связанные документы, показывает замечания и позволяет применять выбранные правки в режиме рецензирования.

## Что нужно

- Windows, настольный Word с WebView2, Python 3.11+ и Node.js с npm.
- Для рабочего анализа — доверенная папка методики, совместимая с реестром [actions.yaml](actions.yaml), и настроенный движок OpenRouter, Codex CLI или Claude Code. Корпоративные навыки, плейбуки, формы и ключи в этот репозиторий не входят. Для DaData нужны собственные ключи.
- Для извлечения текста из вложенных файлов и типовых форм нужен совместимый модуль `tools/doc_ingest/router.py` в настроенной доверенной папке. Приложение исполняет этот модуль с правами пользователя. Выбирайте только проверяемый код из доверенного источника.

## Запуск из исходников

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e '.[tray,dev]'
npm --prefix addin ci
npm --prefix addin run build
.\.venv\Scripts\python -m tray
```

При первом запуске приложение создаёт сертификат для локального HTTPS и просит добавить его в доверенные для текущего пользователя. Если политика организации это запрещает, согласуйте установку с администратором. Добавьте в Word манифест `addin/manifest.xml` через доверенный каталог надстроек. В окне приложения в трее укажите папку методики и настройте движок. Затем нажмите **«Выдать код панели»** и вставьте одноразовый код в панель Word. Он действует пять минут. После выхода из приложения и повторного запуска потребуется новый код. Данные и учётные записи внутренней версии автоматически не импортируются.

Для демонстрации без Word, договоров и ключей запустите после сборки панели `.\.venv\Scripts\python tools/dev_server.py`. В терминале появятся локальный адрес и код подключения. В демонстрации используются синтетический профиль и подставные ответы движков.

## Свой чек-лист и типовые формы

- Чек-лист и его схему положите в `profile/knowledge/contract-checklist/` настроенной папки. Имена файлов: `word-contract-checklist.md` и `contract-checklist-response-schema.md`. Для работы кнопки необходим совместимый навык `word-contract-checklist`. При отсутствии любого файла проверка недоступна. Тестовая схема в проекте показывает структуру, а не готовые критерии.
- SharePoint выключен до ввода URL. Укажите HTTPS-адрес папки своего доверенного SharePoint Server с Windows-аутентификацией (NTLM). Используется текущая учётная запись Windows, поэтому согласуйте адрес со своим администратором. Надстройка читает каталог и скачивает только выбранную форму во временную локальную копию. Не меняет, не пересохраняет и не заменяет оригиналы и ничего не загружает обратно.

## Данные и сборка

Хост слушает только `127.0.0.1`. Выбранный движок может передавать текст внешнему провайдеру после локальной псевдонимизации. Она эвристическая, не исключает все персональные и коммерческие сведения. Используйте только документы, которые разрешено обрабатывать выбранным сервисом. См. [SECURITY.md](SECURITY.md).

Тесты: `python -m pytest -q`, `npm --prefix addin run typecheck` и `node --test addin/tests/*.test.cjs`. Для локальной сборки Windows MSI см. `installer/build.ps1`. Готовые MSI в поставку не входят. Перед распространением сборки отдельно проверьте условия лицензий включённых зависимостей.
