# Безопасность

- Приложение предназначено для локальной установки на Windows и не должно выставляться в сеть. Хост слушает только loopback. Страница панели доступна без токена, операции API требуют токена. Панель получает его после ввода одноразового кода из родного окна приложения. Проверки Host и Origin уменьшают риск запросов со сторонних веб-страниц. Код и токен следует считать секретами; перезапуск хоста отзывает действующие токены.
- Свободный текст договора, приложений и инструкции может содержать чувствительные данные. Локальная обработка убирает распознаваемые шапку и реквизиты и заменяет известные категории значений, но не является гарантией полной анонимизации. Тип договора и роль ограничены безопасными вариантами на сервере. Суммы и даты могут оставаться. Используйте только разрешённый для данных режим и провайдера.
- OpenRouter видит обезличенный текст и может читать разрешённые материалы из временного снимка профиля. Пользовательские профили могут содержать закрытую методику. Используйте доверенную папку и убедитесь, что включённые материалы можно передавать провайдеру. У Codex CLI и Claude Code могут действовать дополнительные настройки самого CLI; рабочая папка не заменяет ограничения доступа процесса.
- SharePoint-запросы только GET к настроенному HTTPS-источнику. Перенаправления не следуют. Оригиналы не меняются. Для DaData передаётся только выбранный ИНН или ОГРН. Ключи приложения хранятся в Windows Credential Manager либо задаются явно через переменные `WAC_PUBLIC_OPENROUTER_API_KEY`, `WAC_PUBLIC_DADATA_API_KEY`, `WAC_PUBLIC_DADATA_SECRET_KEY`.
- Установщик включает настройку доверия локальному TLS-сертификату. Не используйте общесистемный вариант без проверки администратора. Пилотные MSI без подписи не предназначены для публичного распространения.

Сообщайте об уязвимостях через приватный механизм отчётности, если он включён в репозитории, либо напрямую владельцу. Не прикладывайте договоры, ключи и сетевые идентификаторы к публичным задачам.
