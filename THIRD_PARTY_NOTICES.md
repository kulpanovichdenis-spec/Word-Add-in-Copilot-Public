# Сторонние компоненты

Лицензия этого репозитория не заменяет лицензии стороннего ПО. Исходный репозиторий не включает дистрибутивы зависимостей, Office, CLI сторонних поставщиков или готовые MSI.

- Зависимости Python перечислены в `pyproject.toml`; версии сборочного окружения — в `requirements-build.lock`. Условия и уведомления сопровождают соответствующие дистрибутивы Python.
- Сборочные зависимости панели указаны в `addin/package-lock.json`. Типы Office.js — MIT; TypeScript — Apache-2.0. Клиентская библиотека Office.js загружается с CDN Microsoft в соответствии с условиями Microsoft.
- PyMuPDF распространяется по AGPL или коммерческой лицензии. Скрипт локальной сборки MSI включает этот компонент; лицензия на исходники надстройки не даёт разрешения на распространение такой сборки.
- OpenRouter, Codex CLI, Claude Code, DaData и SharePoint подключаются отдельно и применяют собственные условия.

Этот файл — указатель для работы с исходниками. Для распространяемой бинарной сборки нужно отдельно сформировать перечень реально включённых компонентов и их лицензионных уведомлений.
